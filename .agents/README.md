# ai-docs

Documentação central do projeto para ferramentas de IA e desenvolvedores.

> **Regra principal:** qualquer decisão técnica relevante tomada no projeto
> deve ser documentada aqui **antes de fechar o PR**.

---

## Arquivos

| Arquivo                             | Conteúdo                                   |
| ----------------------------------- | ------------------------------------------ |
| [`project.md`](project.md)          | Visão geral, stack e estrutura do monorepo |
| [`conventions.md`](conventions.md)  | Padrões de código, commits e nomenclatura  |
| [`workflows.md`](workflows.md)      | Fluxos de desenvolvimento e documentação   |
| [`decisions/`](decisions/README.md) | ADRs — registro de decisões arquiteturais  |
| [`skills/`](skills/)                | Instruções especializadas por domínio      |

---

## Para ferramentas de IA

Leia nesta ordem:

1. `project.md` — entenda o projeto
2. `conventions.md` — siga as convenções
3. `skills/<domínio>.md` — instruções específicas da tarefa em mãos
